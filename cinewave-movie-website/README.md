# CineWave Movie Website

A responsive movie discovery website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in any modern browser.

## Free hosting
You can deploy this folder to GitHub Pages, Cloudflare Pages, Netlify, or another static-hosting provider.

## Customize
Edit the `movies` array in `script.js` to add your own movie data. Use posters, trailers and viewing links that you have permission to use. The demo links are placeholders and the site does not host copyrighted films.

## Files
- index.html
- style.css
- script.js
